Лабораторная работа

Перед выполнением Лабораторной работы убедитесь, что каждая таблица с данными находится на новом листе. Для удобства переименуйте каждый лист в соответствии с названием таблицы.

Тема 1. Работа с данными 

Задание №1. Качество данных
Проверьте качество собранных Вами данных (всех 14 таблиц!): наличие пропусков, дубликатов, выбросов, соответствие категорий столбцов формату данных в них. При необходимости скорректируйте данные.

Задание №2. Описательная статистика
Выведите описательную статистику для каждой таблицы с данными.

Задание №3. Визуализация данных
Постройте гистограммы распределения и графики «ящик с усами» для каждой таблицы с данными.


Тема 2. Кластеризация 

Задание №1. Создание новой таблицы
Создайте новую таблицу «Кластеризация» со следующими столбцами: регионы, зависимая переменная (у) и все независимые переменные (х1-х13): сначала возьмите для каждой таблицы собранных данных по каждому региону среднее значение по каждому году, затем вычислите среднее из полученных средних, далее сохраните полученные столбцы в созданную таблицу (таким образом, должна получиться таблица, состоящая из 15 столбцов и строк, равных количеству регионов).

Задание №2. Визуализация данных
Постройте тепловую корреляционную матрицу.

Задание №3. Выделение нетипичных регионов
Стандартизируйте данные в таблице «Кластеризация». Методом Ближайшего соседа выделите нетипичные регионы и проведите их дальнейшее исследование (по каким факторам выделенные регионы нетипичны, почему так могло произойти). Удалите выделенные нетипичные регионы из таблицы и сохраните результаты в новой таблице «Кластеризация_1.0». 
(Не более 15 нетипичных регионов!)

Задание №4. Отбор информативных факторов
Выведите вектор корреляции зависимой переменной со всеми независимыми переменными. Проведите кластерный анализ факторного пространства (х1-х13). Для этого подготовьте данные (транспонируйте таблицу «Кластеризация_1.0»). Поэтапно произведите отбор информативных факторов на основе полученных дендрограмм и вектора корреляции. Создайте новую таблицу «Кластеризация_2.0», содержащую только информативные факторы.

Задание №5. Кластеризация данных
Проведите кластеризацию данных по обеим таблицам: «Кластеризация_1.0» и «Кластеризация_2.0» следующими методами: Ближайшего соседа, Дальнего соседа, Уорда, k-средних, fanny (+1 метод на Ваш выбор). Выведите коэффициенты согласованности полученных результатов. Составьте таблицы частот попадания региона в кластер для обеих таблиц («Кластеризация_1.0» и «Кластеризация_2.0»). В таблицах частот определите наиболее вероятный кластер для каждого региона, где это возможно (с вероятностью 0,75 (по четырем методам: Ближайшего соседа, Дальнего соседа, Уорда, k-средних). Сравните полученные результаты с вероятностями попадания региона в кластер в методе fanny и результатами кластерного анализа, проведенного методом на Ваш выбор.

Задание №6. Дискриминантный анализ
Сформируйте обучающие правила (два правила: по одному для каждой таблицы) на основе полученных таблиц частот и получите линейные дискриминантные функции (две), с помощью которых заполните пропуски в таблицах частот присвоения номера кластера региону.

Задание №7. Профилирование
Постройте профили кластеров (2 разных: по одному для каждой таблицы). Опишите полученные кластерные структуры. Подумайте, можно ли условно отнести какие-нибудь нетипичные регионы к полученным кластерам. 
Сравните полученные результаты по двум кластерным структурам.

Таким образом, по итогам выполнения заданий Темы 2 Вы должны получить две устойчивые кластерные структуры.


Тема 3. Построение моделей 

Задание №1. Множественная регрессия
Постройте модель множественной регрессии по данным из таблицы «Кластеризация», затем также постройте модели множественной регрессии для каждого кластера отдельно по полученным двум кластерным структурам. (Убедитесь, что построенные Вами модели являются статистически значимыми). Опишите полученные модели и сравните результаты.


Тема 4. Логистическая регрессия (5б)

Создайте новую таблицу «Логрегрессия» со следующими столбцами: Регионы, Дата (01.01.2018-01.09.2024), Y, Среднее_1 (для каждого года рассчитывается среднее значение), Среднее_2 (среднее значение рассчитанных средних по годам), Медиана (медианное значение по столбцу Среднее_2), Y1 (бинарная переменная, которая рассчитывается следующим образом: если Y>Медианы (Среднее_2), то ставится 1, если Y≤Медианы (Среднее_2), то ставится 0), далее идут столбцы без изменений X1-X14. 

Постройте в Python логистическую регрессию зависимости Y1 от X1-X14 со значимыми переменными, поэтапно исключая из модели незначимые факторы и перестраивая модель.
